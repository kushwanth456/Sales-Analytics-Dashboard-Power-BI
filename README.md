# Sales-Analytics-Dashboard-Power-BI
Built an interactive Power BI dashboard by performing ETL in Excel to analyze sales, profit, cost, and discount trends. Created KPI cards, country-wise and product-wise visuals, and filters to support dynamic analysis and business decision-making.
